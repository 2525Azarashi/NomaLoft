# NomaLoft KANSAI

PCワーカー・ノマドワーカーのための、**関西エリア（大阪・京都・神戸）のワークカフェ＆コワーキングスペースを無料OpenStreetMap上に可視化する横画面（ランドスケープ）Webアプリケーション**です。

OS標準の絵文字を一切使用せず（ソースコード内 0件）、京都・北浜のスペシャルティコーヒー誌や建築図鑑を意識した**生成り和紙ベージュ（Washi Linen & Sumi Espresso）**のトーンと、1.6px線画のオリジナルベクターアイコン・建築ヴィネットによって、AI生成特有のテンプレート感を排した人間味あるエディトリアルUIを構築しています。

## 主な特徴・実装済み仕様

### 1. 関西エリア特化（大阪・京都・神戸）
- **収録エリア（左端の縦インデックスレールからワンクリック切替）**:
  - `OSK1 北浜`: 大阪・北浜 / 中之島（川沿いロースタリー、レトロ建築ブックカフェ）
  - `OSK2 梅田`: 大阪・梅田 / 中崎町（昭和長屋リノベロフト、うめきた4Kモニター常設コワーキング）
  - `OSK3 堀江`: 大阪・心斎橋 / 堀江（家具工房併設ワークカフェ）
  - `KYO 京都`: 京都・烏丸御池 / 河原町（坪庭のある京町家ワークラウンジ、鴨川パノラマ窓カフェ）
  - `KOB 神戸`: 神戸・旧居留地 / 元町（天井高4.2mの旧居留地レトロ洋館コワーキング）

### 2. 横画面（100vw x 100vh ランドスケープ・スプリットコックピット）設計
- 縦長LP構造を廃止し、デスクトップ・タブレット横画面で一覧と地図を同時に俯瞰できる3ペイン水平レイアウト（`[1] 左エリアインデックスレール` + `[2] 検索＆スポットカードデッキ` + `[3] ワイドOpenStreetMap＆フローティング計器HUD`）を採用。

### 3. 無料OpenStreetMap タイル ＆ Overpass API リアル店舗重畳
- **APIキー不要・完全無料の OpenStreetMap 公式タイル (`tile.openstreetmap.org`)** を採用。「和紙マップ / 標準OSM」ボタンで紙地図風フィルタと標準配色を即座に切替可能。
- 右上の **「OSM周辺カフェ重畳」** ボタンを押すと、OpenStreetMap の無料 **Overpass API** から表示中座標周辺のリアルな実在カフェ・コワーキングノードをライブ取得し、サブピンとして地図上に重ねて表示します。

### 4. デフォルト絵文字 完全ゼロ（Custom Line-Art SVG Architecture）
- HTML / TypeScript / JavaScript / CSS 全ファイルにおいて Unicode デフォルト絵文字の使用数は **0件**。
- カップ、V60ドリッパー、電源プラグ、回線ボルト、防音マイク、ルート、ブックマーク、チェックインスタンプ、コンフェッティ粒子（珈琲豆・星・木の葉）に至るまで、すべて統一された線画インラインSVGで描画しています。

### 5. 全8種 UI/UX ＆ インフォグラフィック・アニメーション
1. **Kinetic Typography**: 反転フラップのように1文字ずつ立体的に切り替わる見出しキーワードと、ホバー時に波打つエディトリアル・ウェーブ文字。
2. **UI/UX Micro-Animations**: カードやピン上で `SWIPE` / `OPEN` インジケーターに変形するカスタムカーソル、ミシン目入りチケット型チェックインボタン、線画SVGコンフェッティ、Web Audio APIによる「喫茶室アンビエント環境音」、25分集中タイマー。
3. **Infographic Animation**: マップ上部HUDのSVGラジアルアーク計器3連（平均Wi-Fi Mbps・電源カバー率・周辺空席数）＋時間帯コンフォートスパークバー、さらに詳細シート内の **SVG五角形レーダーチャート** ＋ 4項目水平メーター ＋ 時間帯別空席チャート。
4. **Pull to Refresh**: スポット一覧を上端から下に引っ張ると、線画の **V60ハンドドリッパーから珈琲が滴るアニメーション** とともに最新ステータスを再計算。
5. **Skeleton Screen**: 生成り和紙のシマー（Washi Linen Shimmer）が流れるスケルトンカード表示。
6. **Toast**: 左アクセントボーダーと残り時間バー、`UNDO（元に戻す）` アクションを備えたトースト通知。
7. **Bottom Sheet**: 右側ワイドマップの下部からスライドアップし、マップピンを見失わずに詳細を確認・上下ドラッグでサイズ切替＆クローズできる建築ドシエ型ボトムシート。
8. **Swipe Action**: カード右スワイプでパスポート保存（テラコッタ色レイヤー）、左スワイプでチェックイン押印（宇治モスグリーン色レイヤー）。
9. **Auto Complete**: 一致文字ハイライト、`↑` `↓` `Enter` `Esc` キー操作、`/` ショートカットに対応したリアルタイム検索サジェスト。

## API エンドポイント
- `GET /` : 横画面メインアプリケーション配信
- `GET /api/spots` : 関西スポット一覧・現在地からの距離（Haversine）・快適指数・集計サマリー返却
- `GET /api/osm-nearby` : OpenStreetMap Overpass API 連携プロキシ
- `GET /api/autocomplete` : 関西エリア・駅名・店舗名・設備タグのサジェスト返却
- `POST /api/checkin` : チェックインスタンプ記録API
