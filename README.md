## 最新アップデート内容

### 1. 公式カスタム決定版ロゴ（`CT-01` × `CT-04` × ねこマップピン `"o"`）
- **アイコン（`CT-01`）**: 俯瞰のふわふわ白ねこラテアート ＋ コンセント2ピン持ち手 ＋ ミント＆オレンジのWi-Fi電波アーク ＋ オンライン緑ドット。
- **文字ロゴ（`CT-04` × `CT-05` ねこカスタム）**: 丸みのある `Fredoka` ボールド体＋1つ目の `o` の猫耳＋右肩の充電稲妻スパークをベースに、**`Loft` の `"o"` をマップピン型＋猫要素（決定版A: ねこ耳＆白ねこシルエット窓 / 決定版B: ねこ耳＆ぷっくり肉球窓 / 決定版C: ねこ耳＆かぎしっぽ）** に仕上げました。

### 2. 通常マップ画面の「ねこ要素」あしらい（Unicode絵文字ゼロ・100%カスタムSVG）
- **ねこ耳マグピン ＆ 肉球ピン**: 地図上の各スポットピンに小さな猫耳がつき、電源＋Wi-Fi完備店はオレンジのねこマグ、一部対応・Wi-Fiのみ店はクリームねこマグ／肉球マークで表示。
- **肉球ハート・フロート**: ピンを選択すると小さく跳ねて、パステルピンクの「肉球ハート」がふわっと浮かびます。
- **ねこ耳クラスタバッジ**: ズームアウト時のクラスタ丸バッジにも小さな猫耳と電波湯気をプラス。
- **ねこレーダー「いまここ」ピン**: 現在地マーカーもオレンジの猫フェイス＋波紋リング仕様。
- **地図左下の「看板ねこ（香箱座り）」＆ シートつまみのひょっこり猫耳**: 凡例バーの「看板ねこ」をクリックするとゴロゴロ反応します。お気に入り保存済みのカードは肉球スタンプ付きの「お気に入りニャ」バッジに変化。
