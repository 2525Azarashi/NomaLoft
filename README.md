# NomaLoft — 関西のあったかい電源・Wi-Fiカフェ地図

「コーヒー好きの小さな動物たちが営む、あったかい街のカフェ地図」をコンセプトに、関西2府4県（12エリア・実在カフェ＆コワーキングスペース **240軒**）を快適に探せるマップアプリケーションです。

## 最新アップデート内容

### 1. 阪急沿線（神戸線・宝塚線・京都線・支線）の実在個人カフェ・自家焙煎所を大幅追加（全240軒！）
- **全体収録数**: **240軒**
  - コンセントあり: **209軒** / Wi-Fiあり: **232軒** / コワーキング・ワーク施設: **43拠点**
  - **阪急沿線スポット**: **90軒**（うち **阪急沿線の個人カフェ・自家焙煎所 58軒**！）
  - **関西全域の個人店・ロースタリー**: **118軒**
- **ワンタップ絞り込みピルを新設**:
  - 左パネルのフィルタバー先頭に **「阪急沿線」** と **「個人店・焙煎所」** ピルを追加。2つを同時ONにすれば「阪急沿線の個人カフェだけ（58軒）」を一発抽出でき、「コンセントあり」との掛け合わせも可能です。
  - 阪急沿線の店舗カードにはマルーンカラーの **「阪急沿線」** ミニバッジも表示されます。

## エンドポイント一覧
- `GET /` : メインマップ画面（12エリア・240店舗・阪急沿線＆個人店フィルタ搭載）
- `GET /logos` : 決定版カスタムロゴ（A/B/C）＆バリエーション比較シート
- `GET /api/spots?lat=...&lng=...` : 全240店舗データ・距離・スコアJSON API
- `GET /api/autocomplete?q=...` : 駅名・店名・沿線サジェストAPI
