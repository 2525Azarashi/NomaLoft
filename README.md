### 2. スッキリ見やすい地図ピン ＆ 「ふとしたときの猫の足跡」演出
- **地図上のピン・クラスタ**: 視認性の高いシンプルな**マグカップピン・コーヒー豆ピン・湯気クラスタバッジ・オレンジ波紋の現在地ドット**を採用。
- **ふとした瞬間の可愛らしさ（足跡演出）**:
  1. エリア切替・絞り込み時に、件数表示の横を**小さな4つの足跡が「とことこ…」と歩いてすっと薄くなる**マイクロアニメーション。
  2. エリアジャンプ時、地図の左下余白を**淡い足跡が一瞬だけ横切って消える**さりげない演出。
  3. ブックマークボタンを押した瞬間だけ、**さくらピンクの小さな肉球スタンプがぽんっと浮かんで消える**エフェクト。
  4. リストを一番下までスクロールした末尾や、詳細シート・0件表示の片隅にだけひっそり残る**薄いラテ色の足跡**。
