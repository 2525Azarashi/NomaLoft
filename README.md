# NomaLoft — 関西のあったかい電源・Wi-Fiカフェ地図

「コーヒー好きの小さな動物たちが営む、あったかい街のカフェ地図」をコンセプトに、関西（大阪・京都・神戸・阪神・奈良・滋賀）の実在カフェ＆コワーキングスペース99軒を快適に探せるマップアプリケーションです。

## 最新のUI/UX改善ハイライト

### 1. ピンクラスタリング ＆ ラベル表示最適化（`Leaflet.markercluster`）
- **使用プラグイン**: `Leaflet.markercluster` (v1.5.3)
- ズームアウト時は近接スポットを**湯気マーク付きのふわっとした丸バッジ（例: 24）**にまとめ、タップで自動ズーム展開。
- 個別ピンは小さな**マグカップ型（電源＋Wi-Fiあり＝オレンジマグ / 一部のみ＝クリームマグ）**および**コーヒー豆型（電源なし・Wi-Fiのみ）**のSVGで表示。
- 店名ラベルは常時表示せず、**高ズーム時（zoom >= 16）・選択中の店・リストでホバー中の店のみ**表示することで地図の視認性を大幅に向上。
- ピン選択時は小さく跳ねて、パステルピンクのハートが1つふわっと浮かびます。

### 2. 地図とリストの双方向連動 ＆ 表示範囲フィルタ
- **カードクリック** → クラスタを自動展開して該当ピンへ移動し、ピンを拡大＆詳細シートを表示。
- **カードホバー** → 地図上の該当ピンが拡大し、店名ラベルが一時表示。
- **地図ピンクリック** → 左リストが該当カードの中央位置までスムーズスクロールしてハイライト。
- **地図範囲連動** → 地図をドラッグ・ズームすると上部に **「この地図の範囲でさがす（◯軒）」** ピルボタンが出現し、見えている範囲の店舗だけにリストを絞り込み可能。

### 3. 「いまここ」ボタン・カード重なり解消・情報整理
- **「いまここ」ボタン**: `white-space: nowrap` と最小幅を指定したピルボタン＋地図右下の丸アイコンボタンを配置し、縦折れを完全防止。
- **カードの文字重なり解消**: カード背景を不透明なクリームグラデーション（`#FFFFFF` → `#FFF9F1`）にし、スワイプ背景レイヤーを通常時 `opacity: 0; visibility: hidden` に制御。下部アクション行も1レイヤーに統合。
- **エリアタブ＆件数付きフィルタ**: 選択中は塗りつぶしオレンジ＋白文字、未選択は白地＋薄ブラウン細枠で統一し、各フィルタに該当件数を併記。
- **カップキャラの表情変化**: 通常・読み込み中（ゆらゆら湯気）・ブックマーク時（にっこり顔）・検索0件時（しょんぼり顔「見つからなかったよ…」）の4差分SVGを搭載。
- **アクセシビリティ**: `prefers-reduced-motion: reduce` 環境ではアニメーションを自動的に無効化。
